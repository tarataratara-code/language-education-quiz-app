# 言語・教育 確認問題マスター

`【課末テスト対策】言語・教育_第1回~10回確認問題.pdf`、赤本「言語と教育」、教授法問題集、TCJ「言語と教育」セクション001〜020を、全問正解まで回せる静的ミニアプリにしたものです。

## 使い方

1. `index.html` をブラウザで開く
2. 回・モードを選ぶ
3. 選択肢を選んで回答する
4. 解説と、ややこしい問題の図解を確認する
5. 正答が違うと感じた問題は「選んだ選択肢を正答に修正」で保存する

## 一覧と復習

- 「一覧」タブで、問題・答え・前回の選択・解説をまとめて確認できます。
- 一覧は「全問」「間違えた問題だけ」「未マスターだけ」「自信なしだけ」で絞り込めます。
- 「この条件で練習」を押すと、その条件の問題だけを繰り返し解けます。
- 練習画面の「今日の弱点」からも「間違いだけ練習」を開始できます。

## 注意

第1回〜第10回の教材には解答がないため、正答はPDF本文からの推定です。赤本第2〜4章は付属解答で照合済みです。修正した正答と学習履歴は、ブラウザのローカル保存に残ります。

## GitHub Pagesで公開する

このアプリは静的ファイルだけで動くため、GitHub Pagesで公開できます。

1. `CCbooster` フォルダをGitHubリポジトリにアップロードする
2. GitHubのリポジトリ画面で `Settings` → `Pages` を開く
3. `Build and deployment` の `Source` を `GitHub Actions` にする
4. `main` ブランチに反映すると、`.github/workflows/pages.yml` が `language-education-quiz-app` フォルダだけを公開します
5. Actionsの実行が終わると、PagesのURLが表示されます

## スマホのホーム画面に追加する

公開されたGitHub PagesのURLをスマホで開き、共有メニューから「ホーム画面に追加」を選ぶと、アプリのように起動できます。

- iPhone: Safariで開く → 共有 → ホーム画面に追加
- Android: Chromeで開く → メニュー → アプリをインストール、またはホーム画面に追加

PWA用に `manifest.webmanifest`、`sw.js`、アイコンを設定済みです。ローカルの `file://` ではPWA登録されませんが、GitHub PagesのHTTPS URLでは有効になります。
